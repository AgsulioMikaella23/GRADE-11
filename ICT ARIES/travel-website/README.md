# Travel Website

This project is a simple travel website that showcases various travel destinations and provides a contact form for users to reach out. The website is built using HTML and internal CSS, ensuring a modern and responsive design.

## Project Structure

```
travel-website
├── index.html        # Main page of the travel website
├── contact.html      # Contact form page
├── images            # Folder containing all images used in the website
└── README.md         # Documentation for the project
```

## Features

- **Navigation Bar**: Includes internal links to Home, Destinations, and Contact.
- **Hero Section**: Features a background image with CSS animations.
- **Destination Cards**: Displays at least five destination cards, each with an image, title, description, and button.
- **Google Maps Embed**: Integrates a Google Maps iframe to show a location.
- **Contact Form**: Allows users to submit their name, email, and a message.

## Setup Instructions

1. **Clone the Repository**: Download or clone the repository to your local machine.
2. **Open the Project**: Navigate to the project directory.
3. **Open `index.html`**: Open `index.html` in your web browser to view the main page.
4. **Navigate to Contact**: Click on the "Contact" link in the navigation bar to access the contact form.

## Images

Ensure that all images used in the website are placed in the `images` folder. The images should include:
- A background image for the hero section (e.g., `hero.jpg`)
- Images for each destination card (e.g., `destination1.jpg`, `destination2.jpg`, etc.)
